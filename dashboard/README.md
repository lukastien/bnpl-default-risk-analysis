# Tableau Dashboard

Clean CSVs for Tableau Public live under `dashboard/data/` (generated by
`python src/export_for_tableau.py`).

## Data sources → charts

| CSV | Chart | Recommended Tableau chart type | Notes |
|-----|--------|----------------------------------|-------|
| `data/delinquency_by_tier_utilization.csv` | Delinquency by risk tier × revolving utilization | **Grouped bar** (or highlight table / heatmap with `default_rate` on color) | Labeled **train** subset only. Columns: `risk_tier`, `revolving_utilization_bucket`, `count`, `default_rate`. |
| `data/collections_funnel.csv` | Collections funnel by risk tier | **Funnel** (or stacked/grouped bar by `stage`) | Stages: `flagged` → `contacted` → `recovered` / `written_off`. **`recovered` and `written_off` are model-projected** (payment-plan success-rate assumption), not observed outcomes — keep that in the title/caption. Filter or small-multiples by `risk_tier`. |
| `data/survival_by_tier.csv` | Time-to-default survival by risk tier | **Line** (`time_months` × `survival_probability`, color = `risk_tier`) | Kaplan–Meier on a **constructed** duration (not observed time). Title must say e.g. “Illustrative KM survival (constructed duration).” |

## Regenerate CSVs

```bash
python src/export_for_tableau.py
```

## Manual steps — Tableau Public

1. Install / open **Tableau Desktop Public Edition** (or Tableau Desktop).
2. **Connect** → **Text file** → select each CSV in `dashboard/data/` (or connect the folder and union/separate data sources).
3. Build three worksheets:
   - **Delinquency:** grouped bar — Columns: `risk_tier`, `revolving_utilization_bucket`; Rows: `default_rate` (or `SUM(count)` with `AVG(default_rate)` on color for a heatmap).
   - **Funnel:** funnel chart — Columns: `stage` (sort: flagged, contacted, recovered, written_off); Rows: `SUM(count)`; Filter or Pages: `risk_tier`. Caption: recovered/written_off are model-projected.
   - **Survival:** line — Columns: `time_months`; Rows: `survival_probability`; Color: `risk_tier`. Caption: constructed duration, not observed time-to-default.
4. Assemble a **dashboard** with the three views, add a short subtitle covering the BNPL/installment framing and honesty notes.
5. **Server** → **Tableau Public** → **Save to Tableau Public** (requires a Tableau Public account).
6. Copy the published workbook URL and paste it below.
